# Getting started

Phycode reads pages & keeps the text. See the [install guide](http://example.test/guide/docs/install.html), or the [reference](https://example.org/reference?x=1&y=2).

## Steps

1. Download the archive.
2. Unpack it and run `make install`.
   - Needs PHP 8.4.
   - Needs curl.
3. Done.
